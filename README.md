# DE — Web Scraping & API Parsing

Проект по сбору и анализу данных об играх из **двух источников**: API сайта **rawg.io** (рейтинги и жанры игр) и веб-скрейпинг **gamalytic.com** через Selenium (данные о выручке). Собранные данные объединяются, очищаются и анализируются.

**Бизнес-задача:** предложить стратегию инвестиций в разработку игр, выявив связь между характеристиками игр (жанр, средний рейтинг, платформа, класс издателя) и их коммерческим успехом (продажи, выручка).

## Источники данных

| Источник | Метод сбора | Что собираем |
|---|---|---|
| **rawg.io** | API (`requests`) | рейтинги, жанры, платформы, издатели, разработчики |
| **gamalytic.com** | Web Scraping (`Selenium`) | выручка, продажи, цена, класс издателя |

## Признаки

**Целевая переменная — `revenue`** (выручка).

| Признак | Тип | Описание |
|---|---|---|
| `name` | текстовый | название игры |
| `copiesSold` | вещественный | количество проданных копий |
| `price` | вещественный | цена игры |
| `revenue` | вещественный | **выручка (целевая переменная)** |
| `reviewScore` | вещественный | средняя оценка пользователей (gamalytic) |
| `rating` | вещественный | средняя оценка пользователей (rawg) |
| `publisherClass` | порядковый | класс издателя (AAA, AA, Indie, Hobbyist) |
| `genres` | категориальный | жанр игры |
| `platforms` | категориальный | платформы выпуска |
| `firstReleaseDate` | datetime | дата первого релиза |

**Классы издателей:** Hobbyist (< $10K), Indie ($10K–$50M), AA ($50M–$500M, ≥2 игр), AAA (> $500M, ≥2 игр).

## Pipeline

**1. Сбор данных (parsing.ipynb):** Парсинг RAWG API (игры, разработчики, издатели, жанры, платформы) и веб-скрейпинг gamalytic.com через Selenium с ожиданием загрузки динамического контента. Весь процесс сопровождается логированием в `scraping.log`.

**2. Объединение датасетов:** Алгоритм сопоставления одинаковых игр с разными написаниями названий (нормализация строк через регулярные выражения) для корректного джойна данных из двух источников.

**3. Очистка данных:** Удаление ненужных колонок; удаление 258 строк с нулевым рейтингом и 4 пропусков в жанрах (незначимо на фоне полного датасета из 5716 строк); приведение даты к `datetime`.

**4. Feature Engineering:** One-Hot Encoding для `platforms` и `genres`, подсчёт числа платформ выпуска, отбор популярных платформ и жанров для анализа.

**5. Анализ и визуализация:** Продажи и средние цены по жанрам, топ-жанры по годам, число игр и продажи по классам издателей, выручка по жанрам в разрезе классов, прибыльность платформ, корреляция Пирсона между выручкой и рейтингом.

## Ключевые выводы

- **Прибыльные жанры зависят от класса издателя:** у крупных издателей (AA/AAA) лидируют Massively Multiplayer, Shooter и RPG, а у Indie/Hobbyist — более простые жанры: Platformer, Action, Card.
- **Самые перспективные платформы — консоли PS5 и Xbox Series S/X:** относительно мало конкурентов и наивысшая средняя выручка на игру.
- **Связь выручки и рейтинга** оценена через корреляцию Пирсона.
- Проанализированы продажи по жанрам, динамика популярности жанров по годам и структура рынка по классам издателей.
